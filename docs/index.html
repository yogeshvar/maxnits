MacBook Pro XDR displays can hit ~1000 nits, but macOS caps everyday use at 600. MaxNits removes the limiter — free, forever, from the terminal.

Install View on GitHub

No purchase. No subscription. No menu bar icon. MIT licensed.

Terminal 
# clone and install
git clone https://github.com/yogeshvar/maxnits.git
cd maxnits
make install

# turn it on
maxnits on

How it works

Two small overlay windows, both using only public macOS APIs — no gamma-table hacks or private frameworks.

1

Activate EDR

A 1×1 pixel invisible window renders a pixel brighter than SDR white, switching the display into Extended Dynamic Range mode and unlocking headroom above the 600-nit ceiling.

2

Multiply everything on screen

A second, fullscreen, click-through overlay uses compositingFilter = "multiply" to scale everything beneath it by a factor above 1.0 — up to your panel's real limit.

Usage

MaxNits runs as a small background daemon; the CLI starts it automatically the first time you need it.

maxnits onTurn the brightness boost on
maxnits offTurn the brightness boost off
maxnits set 70Set the boost to a specific level (0–100)
maxnits up / downNudge the boost by 10% (optional amount)
maxnits statusShow whether it's running and its current level
maxnits quitStop the background daemon entirely
maxnits enable-loginStart MaxNits automatically at login

Why MaxNits

  • ✓Free, forever. No trial, no $5 unlock, no subscription.
  • ✓Open source. MIT licensed — read exactly what it does, or fork it.
  • ✓No menu bar clutter. Pure CLI, controlled from the terminal.
  • ✓Native HUD feedback. A center-screen bezel confirms every change, just like the system brightness keys.

Requirements

  • Best on a Liquid Retina XDR display: MacBook Pro 14"/16" (M1 Pro/Max or later), Pro Display XDR, or other EDR-capable displays.
  • Works with reduced effect on some non-XDR Macs too.
  • macOS 13 Ventura or later.
